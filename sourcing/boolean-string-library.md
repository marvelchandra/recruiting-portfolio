## How to Use These Strings

### Google X-Ray (best for LinkedIn)
Paste directly into Google search bar. Add location if needed:
```
site:linkedin.com/in [your string here] "San Francisco Bay Area" OR "Seattle" OR "New York"
```

### LinkedIn Recruiter
Break the string into individual fields:
- **Title:** use the title variants
- **Keywords:** use the tech stack / skills
- **Location:** set separately in LinkedIn filters

### SeekOut / HireEZ / Gem
These tools accept Boolean strings natively. Paste the full string into the search box.

### Tips
- Always add `-"intern" -"student"` to remove noise
- Use `OR` for synonyms (people title themselves differently)
- Use `AND` to require specific combinations
- Test in Google first — faster feedback loop than LinkedIn Recruiter
- Narrow by company name: add `"Nvidia" OR "Google" OR "Meta"` to source from target companies
